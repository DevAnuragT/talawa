# Method: `passwordConfirm`

## Description

Validates password confirmation.

 **params**:
 * `v`: The password confirmation string.
 * `comparator`: The original password to compare against.

 **returns**:
 * `String?`: Error message if passwords do not match, null otherwise.

## Return Type
`String?`

## Parameters

- `v`: `String?`
- `comparator`: `String?`
