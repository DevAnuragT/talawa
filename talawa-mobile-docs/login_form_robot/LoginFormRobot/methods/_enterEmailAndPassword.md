# Method: `_enterEmailAndPassword`

## Description

Enter credentials in the Login Form.

 **params**:
 * `email`: Email address of the user/admin (i.e. testadmin1@example.com, testuser1@example.com).
 * `password`: Password of the user. (i.e. Pass@123)

 **returns**:
   None

## Return Type
`Future<void>`

## Parameters

- `email`: `String`
- `password`: `String`
